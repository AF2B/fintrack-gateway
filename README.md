# fintrack-gateway

**Source code and issue tracker live on GitLab:**
[https://gitlab.com/andre.borbaaf2b/fintrack-gateway](https://gitlab.com/andre.borbaaf2b/fintrack-gateway)

actual codebase. It is not meant to be cloned for development.
